## Recovery mission logic (Planner Agent)

### What it does

- If the user has **0 Core completions for 2+ consecutive days**, the Planner inserts **exactly 1** Recovery mission (type=`recovery`).
- **Max 1** recovery mission “at a time” (enforced per day by checking for an existing recovery mission expiring today).
- Difficulty scales with **previous streak length** (computed from `streak_log` days where `core_completed >= 5`):
  - 0–7: Easy
  - 8–30: Medium
  - 31+: Hard
- Recovery mission disappears once completed naturally (no special deletion required); it won’t be inserted the next day unless the “2+ days with 0 Core” condition still holds.

### Code

- `alter-ego-backend/agents/planner_agent.py`
  - Added `_recovery_mission_if_needed(user_id)` and appended its output inside `plan_interest_and_escaper_missions(...)`.

## Pet Unlock (Day 7) backend trigger (Cub unlock)

### What it does

- Adds a DB-level trigger so that when a user reaches **7 consecutive qualifying streak days**
  - Qualifying day = `streak_log.core_completed >= 5`
- And if `pet_state.stage = 0` (locked),
  - It updates `pet_state` to:
    - `stage = 1`
    - `unlocked_at = now()`
    - `last_updated = now()`

### Where

- `alter-ego-backend/supabase/schema.sql`
  - Adds column:
    - `ALTER TABLE pet_state ADD COLUMN IF NOT EXISTS unlocked_at timestamptz;`
  - Adds functions:
    - `streak_log_consecutive_qualifying_days(p_uid uuid)`
    - `trigger_pet_unlock_on_streak_7()`
  - Adds trigger:
    - `pet_unlock_on_streak_7` on `streak_log` (AFTER INSERT or UPDATE of `core_completed`)

### Frontend trigger expectation

- On next app open/fetch, Home detects pet stage change 0 → 1 and plays the H2 Pet Unlock overlay animation.
- Roaming begins 2s after overlay exit (frontend behavior to implement separately if not already).
